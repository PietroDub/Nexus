Compatibilidade estrutural

TypeScript compara tipos pelos membros, não pelo nome. Fonte: Type Compatibility.

Regra

x é atribuível a y se x tiver pelo menos os membros de y, cada um compatível. Extra em x é irrelevante. Falta ou tipo mais largo num membro obrigatório de y é erro.

Record vs JsonValue

TipoO que cabe
Record<string, unknown> Só objeto com chaves string. Não: null, array, number. Record.
Prisma.JsonValue string | number | boolean | null | JsonObject | JsonArray. Prisma Json.

Anotação de retorno

findAll(): Promise<A[]> exige que o valor resolvido seja atribuível a A[]. O TypeScript compara o payload do Prisma com A campo a campo. Um campo incompatível derruba o Promise inteiro (o erro menciona then).

Correção no Nexus

Alinhar Node.attributes com Prisma.JsonValue. Não usar as Node[]. Não fazer JSON.stringify ao gravar Json — o Prisma aceita o objeto.
